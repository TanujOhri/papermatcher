# Notebooks Directory

This directory is designated for interactive research, exploratory data analysis (EDA), and experimental prototyping for PaperMatcher-AI.

## Overview
Use this directory for Jupyter notebooks focusing on:
- Exploring arXiv dataset distributions (categories, summaries, token lengths).
- Prototyping text cleaning, tokenization, and stop-word filtering.
- Testing TF-IDF vectorization parameters and cosine similarity ranking.
- Performance profiling and relevance evaluation.

## Directory Policy
- Jupyter checkpoint folders (`.ipynb_checkpoints/`) are ignored by `.gitignore`.
- Keep notebooks modular, well-commented, and reproducible.
