# Dataset Directory

This directory is designated for storing dataset files for PaperMatcher-AI.

## Overview
The application will eventually use a real arXiv research paper dataset containing approximately 287,421 research papers.

## Directory Policy
- Raw datasets, processed paper metadata (e.g., CSV, JSON, Parquet), and compressed archives should be placed here.
- Large data files are tracked by `.gitignore` and must not be committed to version control.
- Ensure any downloaded dataset retains appropriate licensing and citations.
